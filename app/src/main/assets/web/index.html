1. Połączenie z Home Assistantem

Token: w Home Assistancie kliknij swój profil (lewy dolny róg) → zakładka Bezpieczeństwo → Tokeny długoterminowe → Utwórz token. Token zapisuje się tylko w telewizorze i nie jest pokazywany na tej stronie.
